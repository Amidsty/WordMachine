# Vue 对局历史详情

此前迁移 `/game/<id>/detail/`。URL、登录要求和 `GET /api/game/<id>` 保持不变；没有数据库迁移、历史转换或评分公式变更。[播放页及统一 Socket](GAME_PLAYING_UI.md) 也已接管，复用本页的读取与展示组件；真实 MySQL/Chromium 双用户关键流程及后续的 [用户/管理/词典流程](MANAGEMENT_BROWSER_TESTS.md) 分别验证。

## 路由与发布

- Flask 显式路由保留服务端登录守卫，入口 no-store；缺前端构建返回 503，不回退旧模板。对局不存在由受保护 API 返回 404，页面显示错误；HTML 路由本身与旧版一样不查询对局存在性。
- Vue Router 懒加载详情页，大厅的“查看详情”使用 SPA 导航。Vue 播放页收到权威终态后通过原 URL 进入详情，不凭命令回执直接跳转。
- 登录 `next` 白名单新增规范的 `/game/<id>/detail/`，ID 限 1–2147483647；拒绝外部、查询串、前导零和超范围目标。播放页的规范路径也已加入白名单。
- 播放/详情深链接均由 Vue/Vite 提供；Vite 仅代理 API、Socket、健康检查，不放宽 CORS，不再代理旧静态资源或页面。
- 已删除 `templates/game_detail.html`、`static/js/game-detail.js`；对应旧 JS 测试迁到 Vue。本批进一步删除旧播放模板、认证/导航、公共 CSS/脚本及对应旧 JS 回归；已没有旧页面消费者。
- 必须部署匹配的前端构建、后端及资源；不能只切换路由而不更新构建。当前结构 head/readiness 以 [迁移指南](AUTH_MIGRATION.md) 为准。

## 显示已有事实，不修复历史

`features/games/contracts.ts` 定义完整读取协议，复用同源客户端、版本协议和公开用户/状态基本结构；大厅与详情共用对局状态标签。关键计数、ID、重复记录、非有限分数、响应 ID 及未答题英文等在读取边界校验。前端校验不代替后端权限、数据完整性或隐藏答案：真实后端仍只公开已答前缀，不是仅靠 UI 隐藏。

- `snapshot` 明示创建时快照；`legacy_live` 明示现有词典可能与原题不同，不能声称恢复了原题。未知来源拒绝展示，而不是默认快照。
- 答题列表只显示已接受记录；中文/英文只能对应同位置且来源 ID 匹配的题目。旧引用缺失/错位明确提示，不从别的位置或当前词典补查；提前结束也不显示未答英文。
- 结果只按已保存的布尔值显示“正确/错误”，缺失或 NULL 显示“未记录”；不重新比较答案与当前英文。缺少答案文本、连击、随机增量或规则版本时明确显示缺失，不填 `legacy-v1` 等默认值。
- 个人正确/错误/未知数量仅是对实际答题条目的显示计数；Perf 直接取该用户最后一条答题记录。最后一条缺少 Perf 时不能沿用此前 Perf；没有个人答题条目时显示“无答题记录”，不据此断言历史上确未作答，也不能使用兼容汇总中的 0 占位假装成绩。
- 原始 0、负数和有限浮点数保留；Perf 及其增量仅在显示时四舍五入为固定一位小数（如 `1511.1`、`0.0`、`-1.3`），详情和播放页共用格式化函数。Rating、连击等显示不变，不修改接口/存储数值，也不在页面执行评分公式或将舍入结果写回。缺失用户名保留用户 ID 提示；缺失作答者不凭轮次猜身份，明确提示未归入个人统计。未知成员引用也不悄悄丢掉。
- Rating 从 `userrating` 中**按当前 game_id**选择记录，展示本局保存的增量和结算后 Rating，不选最后一条历史，不展示为“当前 Rating”，也不反算结算前余额。缺字段显示缺失，无本局条目显示“无本局评分记录”；不把缺失当作增量 0。
- 等待/进行/取消状态与已结束区分，尚未结算不展示预测 Rating。`ready` 转换报告、可展示记录或前端校验通过都不是旧评分数学/全局审计证明。

`GameOverview.vue`、`GameScores.vue`、`AnswerHistory.vue` 分别展示信息、统计及记录；`presentation.ts` 只做显示投影，不调用或复制 Perf/Rating 公式。使用 Vue 文本转义，用户名、答案、词典名称等不会交给 `v-html`。表格复用 `DataTable` 和键盘可聚焦的滚动区域；答题记录每页 20 条，复用 `PaginationBar`。详情按原题序，播放页复用同一组件显示最新在前，均保留原始位置用于题目对应。

这只是**已读取结果的客户端分页**。服务端仍一次返回全部本局答案及相关用户历史，不宣称数据库分页或长期增长后的响应成本恒定；生产规模性能尚未验收。

## 读取生命周期

- `service.ts` 的 `get()` 验证目标 ID 与响应 ID，读取等待有 10 秒上限；`useGameState` 合并同页在途读取、保留刷新中的已显示行，并在离页/身份变化时取消请求。即使传输忽略 abort，旧响应也不能重新写入已销毁页面。播放页复用同一资源接收校验后的推送，先前 GET 的失败或旧返回不清除新推送。
- 较低版本、倒退题序、终态回到非终态或进行中回到等待状态不覆盖已接受状态。同版本仍可更新用户名/旧词典文本，因为对局版本不是完整对象 ETag。
- 读取错误清除已显示数据并提示重读；仍保留版本/进度基线，不能在错误后接受更旧状态。页面切换和账号/角色变化使用原应用的 keyed RouterView 重建，不跨用户保留页面状态。
- 复用 `usePolling` 每 5 秒只读刷新，包括已结束详情；后台、离线或手动关闭时暂停，恢复后重读，不重叠慢请求。离页清理定时器/监听器；手动刷新也不会并发启动重复读取。
- 详情页无答题、结束、结算或自动重放写请求，不消费命令成功回执作为状态，也没有引入第二套 Socket 客户端。进行中提供 Vue 链接进入播放页；详情自身不建立 Socket 连接。

## 验证范围

新增单元/组件测试覆盖协议及来源、未来英文拒绝、ID 绑定、精度/0/缺失值、本局 Rating 定位、XSS、客户端分页、版本/进度防回退、错误恢复、慢请求合并、离页与换账号取消、过期会话及轮询暂停/清理。

3 项新增 Playwright 用例验证 Flask 构建产物与大厅 SPA 导航、Vite 深链接刷新、服务端匿名 HTML 守卫、只读刷新/提前结束、错误及旧响应处理、分页与 XSS。**业务 API 仍模拟，不能代替真实数据库浏览器验收。**

另新增 2 项真实 MySQL/HTTP 用例，验证登录守卫/详情 shell、当前局与后续局的评分历史区分、未答题英文隐藏，以及旧字段/用户引用缺失仍保持原值、普通读取不修复数据。全部使用隔离实例与合成数据，没有连接业务库或进行历史转换。
